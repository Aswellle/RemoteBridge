# RemoteBridge v1.3.9 发行版

> 发布日期：2026-08-20  
> 桌面端：v1.3.9 | 服务端：v1.0.0 | Web：v1.0.0

---

## 桌面端启动修复（关键，apps/desktop/）

- **修复桌面端启动崩溃**：Electron 28 内置 Node 18 缺少 `tracingChannel` API（Node 19.7+ 新增），导致 fastify@5 / pino@10 在启动时崩溃。升级 Electron 至 v29（内置 Node 20.17），并重新编译 `better-sqlite3` 适配新 ABI（`apps/desktop/package.json`）
- **修复启动白屏**：Vite 开发服务器仅绑定 IPv6 `[::1]:5173`，而 Electron Chromium 优先尝试 IPv4 `127.0.0.1` 导致连接被拒。设置 `server.host: true` 监听所有接口；同时为渲染进程加载添加指数退避重试作为安全网（`electron.vite.config.ts`、`apps/desktop/src/main/window.ts`）
- **修复 shared 包导入崩溃**：`@remotebridge/shared` 通过 workspace 软链解析到 Vite 项目根目录外，导致 Vite 跳过优化、原始 CJS 文件直送浏览器后 ESM 命名导出解析失败（`does not provide an export named 'EVENT_TYPE_COLORS'`）以及 `process is not defined`。通过 `resolve.alias` 直接指向 dist 产物、强制 `optimizeDeps.include`、注入 `process` define 桩解决（`electron.vite.config.ts`）
- **修复缺失的应用图标**：`BrowserWindow` 构造函数未设置 `icon`，导致开发和运行时显示默认 Electron 图标。添加 `icon` 指向 `resources/icon.ico`（`apps/desktop/src/main/window.ts`）

## Web 端改进（apps/web/、README.md）

- **README 头部新增 hook 标语**：在标题下方添加醒目的价值主张"零端口穿透，随处访问你的电脑文件"，中英两版同步（`README.md`、`README.en.md`）
- **关于描述更简明人性**：重写关于段落，首句点明用户价值（零端口、任意浏览器），再补中继机制与 PIN 码配对（`README.md`、`README.md`）
- **徽章更新**：添加 Stars / Forks / Last Commit / TypeScript / Issues 徽章，移除 License 动态检测（改为固定 MIT 徽章避免"未指定"显示）（`README.md`、`README.en.md`）
- **README 末尾添加 Star 请求**：仿照热门开源项目，在 License 后添加支持项目的友好请求，含 Star History 趋势图（`README.md`、`README.en.md`）

## CI / DevOps（.github/workflows/）

- **修复发布流水线 YAML 语法错误**：`finalize`  job 中步骤名含冒号导致 YAML 解析失败（"bad indentation of a mapping entry"），每次推送 0 秒失败。为步骤名添加引号消除歧义（`release.yml`）
- **修复 better-sqlite3 ABI 冲突**：desktop 的 `electron-rebuild` 会覆盖共享的 `better-sqlite3` 二进制为 Electron ABI，导致服务端（运行在原生 Node 22）加载失败。明确区分服务端原生构建与桌面端 Electron 构建（`pnpm rebuild`）

## 测试基础设施（scripts/）

- **新增端到端测试脚本**：`test-e2e.mjs` 通过 Host 模拟器（`host-simulator.mjs`）模拟桌面 Host，完整测试 web 客户端的 PIN 配对 → 连接 → Dashboard → 文件浏览全流程（`scripts/test-e2e.mjs`、`scripts/host-simulator.mjs`）
- **新增前端冒烟测试**：`test-webapp.mjs` 在无 Host 场景下测试页面渲染、PIN 输入格式化、连接按钮状态、设备历史面板、路由守卫与连接失败优雅降级（`scripts/test-webapp.mjs`）
