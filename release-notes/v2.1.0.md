# RemoteBridge v2.1.0 发行版

> 发布日期：2026-09-23
> 桌面端：v2.1.0 | 服务端：v1.0.0 | Web：v1.0.0

---

## 概览

自 v2.0.0 以来，RemoteBridge 桌面端经历了一次**完整 UI/UX 重构**。围绕「克制、层次、原生感」的方向，建立了 Design Token v2 色彩体系与 12 个统一交互组件原语，并基于此重构了设置页（侧边栏导航 + 6 个独立 Section）、客户端、消息、安全日志等全部核心页面。同时新增了**桌面端自动更新**能力——启动时自动检测、一键下载安装，以及**系统浏览器打开外部链接**等体验优化。

**更新规模**：28 commits | 62 files changed | +4,820 / -1,950 lines

---

## 重点内容：你现在可以

- **启动时自动检测新版本**：桌面端启动后静默检查 GitHub Releases，有新版本时设置页「关于」卡片显示更新入口，一键下载并安装。
- **设置页全新侧边栏导航**：左侧分类导航（常规 / 外观 / 连接 / 本地中继 / 文件处理 / 关于），右侧独立 Section 页面，支持脏跟踪与即时保存两种模式。
- **打开 GitHub 仓库与更新日志**：关于页按钮点击后直接在系统浏览器中打开，无需手动复制链接。
- **统一的视觉层次**：surface（canvas / subtle / raised / overlay / hover）+ accent（solid / text / surface / border / ring）+ 5 级圆角半径，全部组件低对比度边框，视觉更克制。
- **12 个统一交互组件原语**：Button / Input / Switch / Badge / StatusDot / IconButton / Section / PageHeader / SettingRow / Divider / EmptyState / ErrorState，全应用视觉一致。

## 新功能

### 桌面端自动更新

`apps/desktop/src/renderer/settings/AboutSettings.tsx`、`apps/desktop/src/main/updater.ts`

- 启动时自动检测 GitHub Releases 最新版本
- 关于页显示检测中 / 可下载 / 下载中 / 已下载 / 错误等完整状态
- 下载进度实时显示（MB / 百分比 / 速率）
- 安装按钮触发 `quitAndInstall()` 自动重启
- 支持开发模式更新检测（`dev-app-update.yml` + `forceDevUpdateConfig`）

### 设置页侧边栏导航重构

`apps/desktop/src/renderer/settings/SettingsShell.tsx`、`apps/desktop/src/renderer/settings/SettingsSidebar.tsx`

- 左侧 6 项分类导航（常规 / 外观 / 连接 / 本地中继 / 文件处理 / 关于）
- 右侧 Section 独立渲染，切换时无状态丢失
- 脏跟踪：编辑后离开前提示保存
- 两种保存模式：即时（主题 / 最小化到托盘 / 开机启动）显式（Relay 地址 / 端口 / 上传路径）

### 6 个独立 Section 组件

`apps/desktop/src/renderer/settings/sections/`

- **General**：语言、开机启动、最小化到托盘
- **Appearance**：主题切换（分段控制）
- **Connection**：Relay URL / API URL / 端口配置
- **Local Relay**：嵌入式中继启动 / 停止 / 实时日志折叠面板
- **File Handling**：上传路径配置（图片 / 视频 / 文档 / 压缩包 / Markdown）
- **About**：品牌卡片（LOGO + 版本 + 系统架构）+ 自动更新 + 外部链接

### 外部链接系统浏览器打开

`apps/desktop/src/main/ipc/system.ts`、`apps/desktop/src/preload/index.ts`

- 新增 `shell:open-external` IPC handler
- 关于页「开源仓库」「更新日志」按钮点击后调用 `shell.openExternal()` 在系统浏览器打开
- preload 暴露 `openExternal()` 类型安全接口

### Design Token v2 体系

`apps/desktop/src/renderer/theme/tokens.css`

## 修复

### 上传跨文件系统失败（EXDEV）

`c43cfa2`：`uploadFinalize` 的 `renameSync` 跨文件系统时抛 `EXDEV`，回退到流式复制 + 删除临时文件，修复 CI `upload-quota.test.ts` 失败。

### P0-03 完整性测试确定性

`7f6cb34`、`e000193`：负向测试的断言改为确定性 fail-fast，匹配 relay binary-path 行为（`decoded.seq !== expectedSeq` → FAILED + onError + connection destroyed），修复 CI 偶发失败。

### 缺失 IPC handler 补全

`e8c027a`：桌面端 `system.ts` 缺失 `system:info`、`system:is-first-launch`、`system:mark-first-launch-done` handler；`logs.ts` 缺失 `logs:access`、`logs:security` handler——导致渲染进程 IPC 调用静默失败。全部补全。

## 升级提醒

### 兼容性

- **数据库**：无 schema 变更，无迁移
- **协议**：与 v2.0.0 完全兼容，无新协议消息类型
- **旧版 Web 客户端**：不受影响
- **自动更新**：需 GitHub Releases 存在高于当前版本的 tag 才会触发；企业内网用户可在设置中关闭自动检测

### 自动更新配置

开发模式需放置 `dev-app-update.yml` 于 `apps/desktop/` 根目录；生产模式自动读取 GitHub Releases。`forceDevUpdateConfig = true` 启用开发模式检测。
